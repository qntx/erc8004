# erc8004

[ERC-8004 Trustless Agents](https://eips.ethereum.org/EIPS/eip-8004) for TypeScript and Rust: [`@qntx/erc8004`](https://www.npmjs.com/package/@qntx/erc8004) (npm, `packages/erc8004`) and [`erc8004`](https://crates.io/crates/erc8004) (crates.io, `crates/erc8004`).

Identity, Reputation and Validation registries, registration and feedback files, agentURI resolution, endpoint-domain verification and `AgentWalletSet` signatures, over the on-chain verified deployments in `data/deployments.json`. Both languages share the vectors in `vectors/` and an anvil end-to-end suite (`e2e/`). See the [documentation](docs/).

Changes are tracked in [CHANGELOG.md](CHANGELOG.md); contributor invariants and the local gate live in [AGENTS.md](AGENTS.md) and [CONTRIBUTING.md](CONTRIBUTING.md).
