[`data/deployments.json`](https://github.com/qntx/erc8004/blob/main/data/deployments.json).

[`scripts/deployments/verify.ts`](https://github.com/qntx/erc8004/blob/main/scripts/deployments/verify.ts)
confirms `getVersion() == "2.0.0"` on all three registries on-chain — no
trust-me address lists. To add a chain, propose the entry in
`data/deployments.json` with a passing verification run.
