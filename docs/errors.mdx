---
title: Errors
description: Shared error model — TypeScript classes and Rust enums use the same codes.
---

TypeScript throws `Erc8004Error` subclasses carrying a stable `code`; Rust
returns `#[non_exhaustive]` error enums with the same `code()` strings. Codes
are one-to-one across languages, so callers on either side can match on a
single vocabulary. Rust enums are non-exhaustive — match with a wildcard arm.

| Code                      | TypeScript                 | Rust                       | Meaning                                               |

## Revert reasons

Contract reverts decode into the shared `RevertReason` enum
(`ContractRevertError.reason` / `ProviderError::Revert`). `Error(string)`
becomes `Revert(message)`, `Panic(code)` becomes `Panic(code)`, the registry
custom errors map to named variants, and unrecognised data stays raw as
`Unknown(data)`.

| RevertReason       | Contract error       |
| ------------------ | -------------------- |
| `SelfFeedback`     | `SelfFeedback()`     |
| `AlreadyRevoked`   | `AlreadyRevoked()`   |
| `AgentNotFound`    | `AgentNotFound()`    |
| `RequestNotFound`  | `RequestNotFound()`  |
| `NotValidator`     | `NotValidator()`     |
| `InvalidResponse`  | `InvalidResponse()`  |
| `Unauthorized`     | `Unauthorized()`     |
| `InvalidDeadline`  | `InvalidDeadline()`  |
| `InvalidSignature` | `InvalidSignature()` |
| `BadWallet`        | `BadWallet()`        |
| `InvalidVersion`   | `InvalidVersion()`   |
| `RequestExists`    | `RequestExists()`    |
| `UnknownRequest`   | `UnknownRequest()`   |
| `Revert(message)`  | `Error(string)`      |
| `Panic(code)`      | `Panic(uint256)`     |
| `Unknown(data)`    | anything else        |
