# erc8004

A Rust implementation of [ERC-8004 Trustless Agents](https://eips.ethereum.org/EIPS/eip-8004): Identity, Reputation and Validation registry clients over any alloy `Provider` (`provider` feature), agentURI resolution (`fetch` feature), registration and feedback files, and `AgentWalletSet` signatures. `--no-default-features` is a sans-IO core that builds for `wasm32-unknown-unknown`. Vector-compatible with [`@qntx/erc8004`](https://www.npmjs.com/package/@qntx/erc8004).

See the [documentation](https://github.com/qntx/erc8004/tree/main/docs).
