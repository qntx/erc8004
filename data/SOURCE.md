# Source data

## `abis/*.json`

Contract ABIs are **generated** by `bun run abi` from the vendored Solidity in
`data/contracts/` via `forge inspect` — they are derived data, not vendored
files. Upstream's committed `abis/` at the same commit is stale relative to its
own contract sources (it omits `isAuthorizedOrOwner`, which the deployed Base
Identity registry answers), so we do not use it.

```bash
git clone https://github.com/erc-8004/erc-8004-contracts /tmp/erc8004-contracts
git -C /tmp/erc8004-contracts checkout <commit>
cp /tmp/erc8004-contracts/abis/*.json data/abis/
```

Then bump the commit above and run `bun run gen`.

## `deployments.json`

Generated by `bun scripts/deployments/verify.ts`. Never edit by hand; see the
"Source data" section of `AGENTS.md` for the inclusion rules.

Note: upstream's ABI at this commit omits `isAuthorizedOrOwner(address,uint256)`
(present in `IdentityRegistryUpgradeable.sol:205`); the vendored file adds that
entry verbatim — the ABI is a strict superset of upstream's.
