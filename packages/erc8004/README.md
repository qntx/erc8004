# `@qntx/erc8004`

[ERC-8004 Trustless Agents](https://eips.ethereum.org/EIPS/eip-8004) for TypeScript: Identity, Reputation and Validation registry actions for viem (`erc8004PublicActions` / `erc8004WalletActions`), registration and feedback files, agentURI resolution and `AgentWalletSet` signatures. Platform-neutral, one subpath per layer. Vector-compatible with [erc8004](https://crates.io/crates/erc8004).

See the [documentation](https://github.com/qntx/erc8004/tree/main/docs).
